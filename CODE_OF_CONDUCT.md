# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about
the work. Harassment and personal attacks are not accepted in issues, pull requests,
discussions or any other project space.

Report unacceptable behaviour privately to the maintainers through the contact address on
the repository's security page, or through a private vulnerability report if nothing else
is available. Reports are handled confidentially. The maintainers decide on consequences,
from a warning to a ban from the project's spaces, as the Contributor Covenant describes.
